# 🎢 Mabalacat City College - Coaster Seat Reservation System

A real-time web application built for **Mabalacat City College** students and drivers to monitor coaster availability and reserve seats on a live schedule.

---

## 🌟 Features

* **Real-time Live Sync:** Powered by Firebase Realtime Database for instant updates across devices.
* **Seat Reservations:** Allows students to select scheduled trips and secure a seat with a 10-minute hold timer.
* **QR Check-in:** Generates a unique check-in QR code for active reservations.
* **Driver Control Panel:** Drivers can log in to mark the vehicle as **Available**, **Unavailable**, **Full**, or **Not Full**.
* **Local Time Integration:** Built-in real-time clock synced to Philippine Standard Time (`Asia/Manila`).

---

## 🛠️ Tech Stack

* **HTML5 / CSS3** (Custom Responsive Layout)
* **JavaScript (ES6 Modules)**
* **Firebase Realtime Database** (Data Persistence & Real-time Sync)
* **QRCode.js** (Client-side QR Generation)

---

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. Make sure you have an active internet connection to sync with Firebase.
